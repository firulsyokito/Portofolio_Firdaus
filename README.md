# 🌟 Muhammad Firdaus (Firuls) — Game Artist Portfolio Website

Website portofolio interaktif bergaya Game Artist & Pixel Art dengan fitur:
- 🌌 **Layered Parallax Scenery**: Langit hero, pantulan air danau, bukit bertingkat, semak-semak, dan batuan karang footer yang bergerak halus mengikuti scroll.
- 🎡 **Curved 3D Infinite Carousel**: Galeri preview proyek berbentuk kurva silinder 3D interaktif yang bisa digeser (drag / swipe / scroll / tombol panah keyboard).
- 🎬 **Video Showcase Player**: Preview cuplikan video gameplay `.mp4` responsif dengan kontrol mute/unmute dan auto-pause hemat resource.
- 🔍 **Full-screen Lightbox Gallery**: Galeri tangkapan layar beresolusi penuh dengan navigasi slide (sebelumnya / berikutnya / keyboard).
- 🛠️ **Super Easy Asset Replacement**: Ganti foto profil, gambar judul, background pemandangan, animasi GIF, video, dan detail proyek **hanya dengan mengedit 1 file**: `portfolio-config.js`!

---

## 📁 Struktur Berkas

```text
portofolio/
├── index.html                 # Struktur utama halaman web (HTML5 semantik & accessible)
├── style.css                  # Gaya tampilan, layout fluid, 3D carousel, dan efek parallax
├── script.js                  # Logika interaktif carousel 3D, parallax, video, dan lightbox
├── portfolio-config.js        # 🌟 PUSAT PENGATURAN: Ganti foto, background, dan teks di sini
├── PANDUAN_MENGUBAH_ASET.md   # Panduan lengkap cara ganti foto & dekorasi
└── assets/
    ├── asset/                 # Foto profil, judul hero, background langit, bukit, semak, kristal, GIF
    ├── footage/               # Video cuplikan gameplay (.mp4)
    └── photo/                 # Screenshot dan cover proyek game
```

---

## ⚡ Cara Cepat Mengganti Foto & Background

Silakan baca dokumen lengkap di:
👉 **[PANDUAN_MENGUBAH_ASET.md](PANDUAN_MENGUBAH_ASET.md)**

Secara singkat, Anda cukup membuka **`portfolio-config.js`** dan mengganti path gambar atau teks sesuai keinginan Anda!
