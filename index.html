ABOUT ME

Halo, saya Muhamad Firdaus El Ghaby — seorang 2D, 3D & Pixel Artist sekaligus mahasiswa Teknologi Game di PENS. Saya fokus menciptakan aset Charakter game, Animasi , Environment, dan UI, serta memiliki pemahaman di bidang Charakter Desain dan Consep Art. Saat ini terbuka untuk peluang magang sebagai 2D/Pixel Artist di studio game profesional untuk terus berkembang bersama tim.

PROJECT FIZ STUDIO

Altalis

Proyek game pixel art di mana saya merancang desain karakter NPC 'Rachel' dengan sprite sheet animasi dasarnya (Idle, Dash, Dead) serta aset UI game. Selain fokus pada visual, saya juga menyusun level design, meracik lore untuk memperkuat world-building, dan mengolah efek suara (SFX) menggunakan Audacity.

Role: Lead 2D & Pixel Artist

PROJECT KAMPUS

Dust March

PROJECT KAMPUS

Role: Pixel Artist & Environment Designer

04

GIMERSIA

Fiz Catcher

Proyek game multiplayer kejar-kejaran di mana saya merancang penuh seluruh elemen UI, mulai dari Main Menu, Player Connection, Pause Menu, hingga layar Win/Lose. 05

VISUAL NOVEL • NARRATIVE RPG

So You Can Rise Once Again

Game naratif interaktif bergaya visual novel emosional yang berfokus pada dialog mendalam dan pilihan bermakna. Bertanggung jawab penuh atas ilustrasi karakter (Sophie), aset background interior kamar yang hangat, perancangan antarmuka kotak dialog bergaya robekan kertas catatan, dan sistem percabangan cerita yang dinamis.

Role: Character Artist & UI Designer
Play On Itch.io
06

CASUAL 3D ARCADE

Carrot Rain

Carrot Rain adalah game aksi kasual 3D bertema petualangan menangkap wortel yang berjatuhan dari langit sebelum waktu habis. Bertanggung jawab atas pemodelan 3D low-poly karakter (rubah & kelinci bertopi keranjang), perancangan lingkungan pepohonan wortel bertingkat, efek pencahayaan cerah, serta elemen antarmuka skor dan timer bertema papan kayu playful.

Role: 3D Artist & Game Designer
Play On Itch.io
